# Contributing

## Research integrity
- Do not describe a finite pattern as a theorem.
- Attach an explicit protocol to every reported result.
- Separate exact mathematical facts from numerical observations and interpretations.
- Record failed experiments and counterexamples.
- Cite original research and distinguish peer-reviewed papers from preprints or commentary.

## Engineering
- Keep configuration declarative and data-only.
- Prefer small modules with explicit contracts.
- Add tests for correctness, edge cases, and invalid input.
- Preserve reproducibility; avoid hidden state and unrecorded randomness.
- Do not add an AI dependency before a baseline experiment demonstrates a need.

## Pull requests
Use focused branches and pull requests for structural changes. Explain the research motivation, implementation, tests, and limitations.
