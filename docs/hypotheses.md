# Initial Hypotheses Register

These are testable starting points, not established discoveries.

| ID | Hypothesis | Status | Proposed test |
|---|---|---|---|
| H-001 | Positional-base changes preserve integer-level properties such as primality. | Mathematical control | Round-trip conversion and exact primality checks. |
| H-002 | Some sequence families have simpler digit-level descriptions in particular bases. | PROPOSED | Compare pre-registered description-length and regularity metrics. |
| H-003 | A task-aware base selector can outperform a fixed-base baseline on selected digit-pattern tasks. | PROPOSED | Train/validation/test split with fixed task definitions. |
| H-004 | Digit-level regularity alone cannot establish a new value-level mathematical law. | Methodological | Construct counterexamples and compare features with exact identities. |

## Status vocabulary
PROPOSED: drafted, not tested.
TESTING: protocol is running.
SUPPORTED: evidence supports the claim within tested scope.
REFUTED: a counterexample or analysis rejects the claim.
PROVEN: a mathematical proof has been checked.
OPEN: unresolved or insufficient evidence.

Empirical support is not proof. Reserve PROVEN for proof, not model confidence or a large test count.
