# Glossary

- Base or radix: number of distinct digit values in a positional numeral system.
- Digit expansion: sequence of digits representing a value in a specified base.
- Representation: symbolic or structural encoding of a mathematical object.
- Invariant: property unchanged under a specified transformation.
- Mersenne number: integer of the form 2^n - 1.
- Conjecture: mathematical statement proposed on evidence but not yet proven.
- Counterexample: instance that disproves a universal claim.
- Symbolic regression: search for an explicit mathematical expression fitting observations.
- Description length: number of symbols or bits required under a declared encoding.
- Normal number: real number whose digit blocks have expected limiting frequencies in a given base.
- Exact arithmetic: computation that preserves values without approximation or rounding error.
