# Open Research Questions

1. Can a representation be selected automatically for a declared task using a metric fixed before searching?
2. Does a shorter digit description correspond to a shorter description of the mathematical object, or only to a convenient encoding?
3. How should description length be normalized across bases with different digit alphabets and symbol costs?
4. Which pattern-discovery methods control false positives when searching many bases, features, and sequences?
5. Can symbolic regression produce conjectures that generalize beyond the observed range?
6. What independent verification layer is needed before an AI-generated conjecture can be labeled mathematically supported?
